# Veiledning om kontakt med NAV

Sammendrag: Servicekontoret kan hjelpe deg med å finne riktig kontaktpunkt når du trenger veiledning.

Hvis saken gjelder økonomisk sosialhjelp, kan kommunen gi informasjon om kommunale tjenester. Hvis saken gjelder statlige ytelser, kan NAV gi veiledning.

Ansvarlig enhet: Servicekontoret.

Neste steg: Kontakt servicekontoret før du sender personlige opplysninger. Noen spørsmål skal til Nav, og servicekontoret kan hjelpe deg videre.
